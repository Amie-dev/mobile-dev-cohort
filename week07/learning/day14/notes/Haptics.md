# 📳 Expo Haptics (`expo-haptics`) — Complete Deep Notes

## What is Expo Haptics?

`expo-haptics` allows your app to provide **physical feedback through vibration and touch sensations**.

Instead of only seeing or hearing feedback, users can **feel** interactions.

Examples:

* Button press vibration
* Successful payment feedback
* Error feedback
* Long press feedback
* Camera shutter feel
* Keyboard tap feel
* Pull-to-refresh feedback

---

# What is Haptic Feedback?

Haptic feedback is a small vibration or tactile sensation generated by the device.

Example:

```txt
You tap a button
      ↓
Phone vibrates slightly
      ↓
You feel the action happened
```

Without Haptics:

```txt
Tap Button
    ↓
Only Visual Feedback
```

With Haptics:

```txt
Tap Button
    ↓
Visual Feedback
    +
Physical Feedback
```

# Haptic Categories

Expo provides three main categories:

```txt
Haptics
│
├── Selection
├── Notification
└── Impact
```

Each is used for different situations.

---

# 1. Selection Feedback

Used when the user changes a selection.

Examples:

```txt
Switch Toggle
Tab Change
Date Picker
Dropdown Selection
```

---

## Selection Haptic

```tsx
await Haptics.selectionAsync();
```

Example:

```tsx
<Button
  title="Select"
  onPress={() => Haptics.selectionAsync()}
/>
```

---

# Real Example

```txt

Dark Mode
```

User changes mode:

```txt

 ↓

```

# Notification Types

| Type    | Usage           |
| ------- | --------------- |

# Example

```tsx

  try {
    await updateProfile();

    Haptics.notificationAsync(
      Haptics.NotificationFeedbackType.Success
    );
  } catch {
    Haptics.notificationAsync(
      Haptics.NotificationFeedbackType.Error
    );
  }
};
```

# Common Mistakes

## Mistake 1

Using haptics on every tap.

❌

```txt
Every Button
Every Scroll
Every Touch
```

Too annoying.

---

## Mistake 2

Using Heavy impact for small actions.

❌

```txt
Open Settings
↓
Heavy Impact
```

Feels wrong.

---

## Mistake 3

Using Error feedback for warnings.

Choose correct type.

---

## Mistake 4

Ignoring accessibility.

Some users disable vibrations.

Always ensure:

```txt
Visual Feedback
+
Haptic Feedback
```

not only haptics.

### Most Common Real-World Usage

```tsx
// Button Press
await Haptics.impactAsync(
  Haptics.ImpactFeedbackStyle.Light
);

// Success
await Haptics.notificationAsync(
  Haptics.NotificationFeedbackType.Success
);

// Tab Change
await Haptics.selectionAsync();
```

These three APIs (`selectionAsync`, `impactAsync`, and `notificationAsync`) cover **90%+ of haptic use cases** in real-world React Native and Expo applications. 📳✨
